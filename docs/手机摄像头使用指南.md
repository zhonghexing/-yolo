# 📱 手机摄像头使用指南

## 概述

本系统支持使用手机摄像头进行实时视频流检测，无需购买专业工业相机。通过 DroidCam 等应用，可以将小米15等手机变成高质量的无线摄像头。

---

## 一、功能特性

### 1.1 核心功能

| 功能 | 说明 |
|------|------|
| **手机视频流检测** | 支持 DroidCam、IP Webcam 等应用 |
| **拍照自动保存** | 自动保存带检测框的标注图片 |
| **图片检测保存** | 检测单张图片时自动保存标注图 |
| **Web 远程监控** | 支持查看原图和标注图 |
| **6MP 图片导出** | 符合竞赛规格的图片导出 |

### 1.2 保存目录结构

```
defect_records/
├── snapshots/          # 拍照统计保存的图片（带标注）
│   ├── 20260604_143025_合格_pass.jpg
│   └── 20260604_143058_缺陷_划痕.jpg
├── annotated/          # 图片检测保存的标注图
│   ├── 20260604_143025_缺陷_划痕_sample01.jpg
│   └── 20260604_143058_合格_pass_sample02.jpg
└── (原有缺陷记录...)
```

## 二、方案对比

| 方案 | 优点 | 缺点 | 推荐场景 |
|------|------|------|----------|
| **DroidCam** | 稳定、支持 iOS/Android、有电脑客户端 | 免费版限制 480p | 日常使用 |
| **IP Webcam** | 功能强大、完全免费 | 仅 Android | Android 用户 |

| **WiFi 连接** | 无线自由、方便移动 | 可能有延迟 | 移动检测 |

## 二、DroidCam 安装配置

### 2.1 手机端安装

**Android 用户：**
1. 打开 Google Play 商店
2. 搜索 **"DroidCam"**
3. 安装 **"DroidCam - Webcam & Mic"**（开发者：Dev47Apps）

**iOS 用户：**
1. 打开 App Store
2. 搜索 **"DroidCam"**
3. 安装 **"DroidCam - Webcam & Mic"**

### 2.2 电脑端安装

1. 访问官网：https://www.dev47apps.com/
2. 下载 Windows 版本
3. 运行安装程序，按提示完成安装
4. 安装完成后会自动安装虚拟摄像头驱动

---

## 三、连接方式

### 3.1 WiFi 连接（推荐）

**优点**：无线自由，方便移动

**步骤**：
1. **确保手机和电脑连接同一个 WiFi 网络**
2. 打开手机上的 DroidCam App
3. 点击底部的 **"Start"** 按钮
4. 记录屏幕显示的 **IP 地址**（如 `192.168.1.100`）和 **端口**（默认 `4747`）

**连接地址格式**：
```
http://<IP地址>:<端口>/video
示例：http://192.168.1.100:4747/video
```

### 3.2 USB 连接（最稳定）

**优点**：延迟最低，不受网络影响

**步骤**：
1. **开启手机 USB 调试**：
   - 设置 → 关于手机 → 连续点击"MIUI版本"7次，开启开发者模式
   - 设置 → 更多设置 → 开发者选项 → 开启"USB调试"
2. 用 USB 数据线连接手机和电脑
3. 手机上弹出"允许USB调试"提示，点击"允许"
4. 打开 DroidCam App，会自动识别 USB 连接
5. 点击 "Start"

**连接地址**：
- USB 连接时，DroidCam 会自动创建虚拟摄像头，无需手动输入地址

## 四、在检测软件中使用

### 4.1 方法一：使用虚拟摄像头（推荐）

这是最简单的方式，DroidCam 会创建一个虚拟摄像头设备。

**步骤**：
1. 先启动 DroidCam：
   - 打开手机 DroidCam App
   - 打开电脑 DroidCam 客户端
   - 点击 "Start" 连接
2. 打开钢材缺陷检测系统
3. 切换到 **"摄像头检测"** 模式
4. 在摄像头下拉框中选择 **"DroidCam"** 开头的设备
5. 点击 **"启动摄像头"**

### 4.2 方法二：直接输入流地址

如果虚拟摄像头方式不工作，可以直接输入视频流地址。

**步骤**：
1. 打开钢材缺陷检测系统
2. 切换到 **"摄像头检测"** 模式
3. 点击工具栏或右侧面板的 **"📱 手机摄像头"** 按钮
4. 在弹出的对话框中输入 DroidCam 的流地址：
   ```
   http://192.168.1.100:4747/video
   ```
5. 选择分辨率限制（推荐选择"限制为 1080p"）
6. 点击 "确定"

## 五、分辨率设置

### 5.1 DroidCam 分辨率设置

**免费版**：最高 480p
**付费版（DroidCamX）**：支持 720p、1080p

**设置方法**：
1. 打开电脑 DroidCam 客户端
2. 点击右上角的设置图标
3. 选择视频分辨率

### 5.2 检测软件分辨率限制

在连接手机摄像头时，可以选择输出分辨率限制：

| 选项 | 分辨率 | 说明 |
|------|--------|------|
| 原始分辨率 | 不限制 | 使用手机原始分辨率 |
| 限制为 6MP | 3072×2048 | 符合竞赛规格 |
| 限制为 1080p | 1920×1080 | 推荐，平衡性能和质量 |
| 限制为 720p | 1280×720 | 最流畅 |

**建议**：
- 网络稳定：选择"限制为 1080p"
- 网络不稳定：选择"限制为 720p"
- 竞赛导出：选择"限制为 6MP"

## 六、常见问题解决

### 6.1 连接失败

**问题**：无法连接到手机摄像头

**解决方案**：
1. **检查网络**：确保手机和电脑在同一 WiFi 网络
2. **检查防火墙**：Windows 防火墙可能阻止连接
   - 打开 Windows 安全中心 → 防火墙 → 允许应用通过防火墙
   - 添加 DroidCam 到允许列表
3. **检查 IP 地址**：确认输入的 IP 地址正确
4. **重启应用**：关闭并重新打开 DroidCam

### 6.2 视频卡顿

**问题**：视频流不流畅，有延迟

**解决方案**：
1. **降低分辨率**：选择"限制为 720p"
2. **使用 USB 连接**：USB 连接延迟最低
3. **关闭其他应用**：减少网络占用
4. **靠近路由器**：增强 WiFi 信号

### 6.3 画面模糊

**问题**：检测画面不清晰

**解决方案**：
1. **清洁手机镜头**：用软布擦拭镜头
2. **稳定手机**：使用手机支架固定
3. **调整光线**：确保光线充足均匀
4. **提高分辨率**：使用 DroidCamX 付费版

### 6.4 检测不准确

**问题**：缺陷检测结果不理想

**解决方案**：
1. **固定拍摄距离**：保持手机与被测物体距离一致
2. **控制光照**：使用补光灯，避免阴影
3. **调整置信度**：在软件中调整置信度阈值
4. **选择合适分辨率**：不要过低，也不要过高

## 七、最佳实践

### 7.1 硬件准备

| 设备 | 推荐 | 说明 |
|------|------|------|
| **手机支架** | 三脚架或桌面支架 | 固定手机，避免抖动 |
| **补光灯** | LED 环形灯 | 提供均匀光照 |
| **背景板** | 纯色背景 | 减少干扰 |

### 7.2 拍摄环境

1. **光照均匀**：避免强烈阴影和反光
2. **背景简洁**：使用纯色背景，减少干扰
3. **距离固定**：保持手机与被测物体距离一致（建议 20-30cm）
4. **角度垂直**：手机镜头正对被测物体

### 7.3 软件设置

**推荐配置**：
- 检测模式：摄像头检测
- 分辨率限制：1080p
- 置信度阈值：0.25
- 自动保存缺陷图：开启

## 八、竞赛使用技巧

### 8.1 快速检测流程

1. **准备阶段**（30秒）：
   - 启动 DroidCam
   - 连接手机和电脑
   - 打开检测软件

2. **检测阶段**（150秒）：
   - 切换到摄像头模式
   - 点击"启动摄像头"
   - 将钢材样品放在手机镜头前
   - 点击"拍照统计"记录结果

3. **导出阶段**：
   - 点击"导出报告"
   - 或点击"导出 6MP"保存单张图片

### 8.2 符合竞赛规格

**设备规格要求**：
- 像素：≤ 600万（3072×2048）
- 输出：6MP 图片

**实现方式**：
1. 使用手机拍摄（像素远超 600万）
2. 软件自动缩放到 6MP
3. 导出符合规格的图片

## 九、图片自动保存功能

### 9.1 拍照统计自动保存

**触发方式**：点击"拍照统计"按钮或按 `Space` 键

**保存位置**：`defect_records/snapshots/`

**文件命名**：`{时间戳}_{判定}_{缺陷类型}.jpg`

**示例**：
```
20260604_143025_合格_pass.jpg
20260604_143058_缺陷_划痕.jpg
20260604_143112_缺陷_夹杂_斑块.jpg
```

**保存内容**：带检测框和标签的标注图片

### 9.2 图片检测自动保存

**触发方式**：点击"开始检测"按钮

**保存位置**：`defect_records/annotated/`

**文件命名**：`{时间戳}_{判定}_{缺陷类型}_{原文件名}.jpg`

**示例**：
```
20260604_143025_缺陷_划痕_sample01.jpg
20260604_143058_合格_pass_sample02.jpg
```

**保存内容**：原图 + 检测框标注

### 9.3 功能对比

| 场景 | 保存位置 | 文件名格式 | 说明 |
|------|----------|------------|------|
| **拍照统计** | `snapshots/` | `{时间}_{判定}_{缺陷}.jpg` | 视频帧 + 检测框 |
| **图片检测** | `annotated/` | `{时间}_{判定}_{缺陷}_{原名}.jpg` | 原图 + 检测框 |
| **批量检测** | 根目录 | `{时间}_{缺陷}.jpg` | 原图复制（原有功能） |

## 十、Web 远程监控

### 10.1 启动 Web 监控

**方式一**：菜单启动
1. 点击菜单 → 监控 → 启动 Web 监控
2. 浏览器会自动打开监控页面

**方式二**：快捷键
- 按 `Ctrl+W` 启动 Web 监控

**访问地址**：
- 本机访问：http://localhost:5000
- 局域网访问：http://<本机IP>:5000

### 10.2 查看检测图片

**最近检测记录**：
1. 点击"查看"按钮
2. 在弹出的模态框中切换"原图"或"标注图"

**检测历史**：
1. 点击"原图"按钮查看原始图片
2. 点击"标注"按钮查看带检测框的标注图

### 10.3 模态框操作

| 操作 | 方法 |
|------|------|
| 切换图片 | 点击顶部"原图"或"标注图"标签 |
| 关闭模态框 | 点击右上角 X 或点击背景 |
| 查看大图 | 图片自动适应屏幕大小 |

### 10.4 Web 监控功能

| 功能 | 说明 |
|------|------|
| 实时监控 | 显示检测统计、缺陷趋势 |
| 检测历史 | 查询所有检测记录 |
| 图片预览 | 查看原图和标注图 |
| 报警配置 | 按类别设置报警阈值 |
| 缺陷分布 | 各类缺陷数量统计 |
| 严重程度 | 严重/中等/轻微分布 |
