## 1. 数据集概述

### 1.1 数据集目标

本数据集用于训练和评估工业螺丝缺陷检测模型，需满足以下目标：

| 目标 | 具体要求 |
|------|----------|
| 覆盖全面 | 覆盖6种缺陷类型，每种类型充分样本 |
| 质量可靠 | 图像清晰，标注准确，边界框精确 |
| 多样性 | 不同光照、角度、背景条件下的样本 |
| 平衡性 | 各类别样本数量相对均衡 |
| 可扩展 | 支持后续新增缺陷类型和样本 |

### 1.2 缺陷类型定义

| 类别ID | 中文名称 | 英文名称 | 定义 | 判定标准 |
|--------|----------|----------|------|----------|
| 0 | 正常件 | Normal | 无任何缺陷的合格螺丝 | 表面光滑，形状完整，规格正确 |
| 1 | 轻微划痕 | Minor Scratch | 表面浅层划痕 | 划痕深度<0.1mm，长度<5mm |
| 2 | 严重划痕 | Severe Scratch | 表面深层划痕 | 划痕深度≥0.1mm或长度≥5mm |
| 3 | 缺角 | Missing Corner | 螺丝头部或边缘缺损 | 缺损面积>1mm² |
| 4 | 变形 | Deformation | 螺丝形状异常变形 | 弯曲度>2°或椭圆度>5% |
| 5 | 混料 | Mixed Material | 材质或规格混料 | 材质、尺寸、螺纹类型不符 |

### 1.3 数据集规模

| 数据集 | 样本数 | 占比 | 用途 |
|--------|--------|------|------|
| 训练集 | 1500张 | 70% | 模型训练 |
| 验证集 | 450张 | 20% | 训练过程验证 |
| 测试集 | 225张 | 10% | 最终性能评估 |
| **总计** | **2175张** | **100%** | - |

**各类别样本分布**：

| 缺陷类型 | 训练集 | 验证集 | 测试集 | 总计 | 占比 |
|----------|--------|--------|--------|------|------|
| 正常件 | 300 | 90 | 45 | 435 | 20% |
| 轻微划痕 | 250 | 75 | 38 | 363 | 17% |
| 严重划痕 | 250 | 75 | 38 | 363 | 17% |
| 缺角 | 250 | 75 | 38 | 363 | 17% |
| 变形 | 225 | 67 | 33 | 325 | 15% |
| 混料 | 225 | 68 | 33 | 326 | 14% |
| **总计** | **1500** | **450** | **225** | **2175** | **100%** |

### 2.3 采集参数

| 参数 | 要求 | 说明 |
|------|------|------|
| 分辨率 | 1920×1080 或更高 | 保证细节清晰 |
| 帧率 | 15-30 fps | 静态拍摄可降低 |

| 条件维度 | 变化范围 | 采样数量 |
|----------|----------|----------|
| 光照强度 | 暗/中/亮 | 每种缺陷×3 |
| 拍摄角度 | 0°/30°/60°/90° | 每种缺陷×4 |
| 背景颜色 | 白/灰/黑 | 每种缺陷×3 |
| 螺丝位置 | 居中/偏左/偏右 | 每种缺陷×3 |

## 3. 图像标注规范

### 3.1 标注格式

采用YOLO格式进行标注，每张图像对应一个同名的`.txt`标注文件。

#### 标注文件格式

```
# 每行一个目标，格式为：
# class_id x_center y_center width height confidence（可选）

0 0.5 0.5 0.3 0.4
1 0.2 0.3 0.15 0.2
```

#### 坐标说明

```
┌─────────────────────────────────────────────────────────────────┐
│                       YOLO坐标格式说明                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   (0,0)────────────────────────────────────────────(1,0)       │
│      │                                                    │       │
│      │              ┌───────────────┐                    │       │
│      │              │    目标物体    │                    │       │
│      │              │               │                    │       │
│      │              └───────────────┘                    │       │
│      │                    │                               │       │
│      │                    │ (x_center, y_center)          │       │
│      │                    │                               │       │
│   (0,1)────────────────────────────────────────────(1,1)       │
│                                                                 │
│   • x_center: 边界框中心点x坐标 / 图像宽度 (归一化到0-1)       │
│   • y_center: 边界框中心点y坐标 / 图像高度 (归一化到0-1)       │
│   • width: 边界框宽度 / 图像宽度 (归一化到0-1)                 │
│   • height: 边界框高度 / 图像高度 (归一化到0-1)                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 标注工具

| 工具 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| LabelImg | 简单易用，支持YOLO格式 | 功能较少 | ★★★★☆ |
| CVAT | 功能强大，支持团队协作 | 部署复杂 | ★★★★★ |
| Roboflow | 在线平台，数据增强集成 | 需联网 | ★★★★☆ |
| Label Studio | 灵活可定制 | 学习曲线 | ★★★☆☆ |

**推荐**：使用LabelImg进行本地标注，Roboflow进行数据管理

### 3.3 标注质量要求

#### 边界框要求

| 要求项 | 具体标准 | 示例 |
|--------|----------|------|
| 紧密度 | 边界框紧贴目标边缘，间距≤2像素 | ✓ 正确标注 |
| 完整性 | 包含目标全部可见部分 | 不能截断目标 |
| 准确性 | 中心点位于目标几何中心 | 偏差≤5像素 |
| 一致性 | 相同缺陷标注方式统一 | 所有标注员标准一致 |

### 4.2 文件命名规范

```

```
格式: 与对应图像文件同名，扩展名为.txt

示例:
- normal_0001_light_0deg.txt
- minor_scratch_0023_medium_30deg.txt
```

## 6. 数据质量控制

### 6.1 质量检查清单

| 检查项 | 检查内容 | 合格标准 | 检查方法 |
|--------|----------|----------|----------|
| 图像质量 | 清晰度、曝光、噪点 | 无明显模糊、过曝、噪点 | 自动检测+人工抽检 |
| 标注准确性 | 边界框位置、类别 | IoU≥0.95 | 自动计算+人工审核 |
| 标注一致性 | 相同缺陷标注方式 | 标注方式统一 | 交叉审核 |
| 类别平衡 | 各类别样本数量 | 最大/最小比≤2 | 统计分析 |
| 重复检测 | 相似/重复图像 | 无重复样本 | 图像哈希对比 |

```

### 7.2 划分代码

```python
import os
import random
import shutil
from pathlib import Path
from collections import defaultdict

def stratified_split(image_dir, label_dir, output_dir, 
                     train_ratio=0.7, val_ratio=0.2, test_ratio=0.1,
                     random_seed=42):
    """
    分层随机划分数据集
    
    Args:
        image_dir: 图像目录
        label_dir: 标注目录
        output_dir: 输出目录
        train_ratio: 训练集比例
        val_ratio: 验证集比例
        test_ratio: 测试集比例
        random_seed: 随机种子
    """
    random.seed(random_seed)
    
    # 按类别分组
    class_samples = defaultdict(list)
    
    for label_file in Path(label_dir).glob("*.txt"):
        with open(label_file, 'r') as f:
            lines = f.readlines()
            if lines:
                # 获取第一个标注的类别
                class_id = int(lines[0].strip().split()[0])
                image_file = label_file.with_suffix('.jpg')
                if image_file.exists():
                    class_samples[class_id].append(image_file)
    
    # 分层划分
    train_files, val_files, test_files = [], [], []
    
    for class_id, files in class_samples.items():
        random.shuffle(files)
        n = len(files)
        n_train = int(n * train_ratio)
        n_val = int(n * val_ratio)
        
        train_files.extend(files[:n_train])
        val_files.extend(files[n_train:n_train + n_val])
        test_files.extend(files[n_train + n_val:])
    
    # 复制文件
    for split, files in [('train', train_files), ('val', val_files), ('test', test_files)]:
        img_dir = Path(output_dir) / split / 'images'
        lbl_dir = Path(output_dir) / split / 'labels'
        img_dir.mkdir(parents=True, exist_ok=True)
        lbl_dir.mkdir(parents=True, exist_ok=True)
        
        for img_file in files:
            shutil.copy(img_file, img_dir / img_file.name)
            lbl_file = img_file.with_suffix('.txt')
            if lbl_file.exists():
                shutil.copy(lbl_file, lbl_dir / lbl_file.name)
    
    print(f"划分完成: 训练集{len(train_files)}张, 验证集{len(val_files)}张, 测试集{len(test_files)}张")

if __name__ == "__main__":
    stratified_split(
        image_dir="data/processed/images",
        label_dir="data/processed/labels",
        output_dir="data"
    )
```

## 附录B：常见标注问题

### 问题1：边界框过大

**问题描述**：标注框包含过多背景区域

**正确做法**：边界框应紧贴目标边缘，留出2-5像素边距即可

### 问题2：遮挡目标处理

**问题描述**：目标被其他物体部分遮挡

**处理原则**：
- 遮挡<30%：标注完整目标
- 遮挡30%-70%：标注可见部分，添加"occluded"属性
- 遮挡>70%：可选择不标注或标注可见部分

### 问题3：多个同类目标

**问题描述**：同一图像中有多个相同类型的目标

**处理原则**：每个目标单独标注一个边界框，即使紧密相邻
