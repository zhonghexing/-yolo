# 钢材缺陷检测系统

基于 **YOLOv8s** 的钢材表面缺陷智能检测系统，支持图像、摄像头和视频实时检测，提供 PyQt5 图形界面和命令行两种操作方式。

## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11 |
| Python | 3.10 或更高版本 |
| 内存 | 8 GB 以上 |
| 硬盘 | 2 GB 可用空间 |
| GPU（可选） | 支持 CUDA 的 NVIDIA GPU 可加速推理 |

## 快速开始

### 1. 安装 Python

从 [python.org](https://www.python.org/downloads/) 下载并安装 Python 3.10+，安装时勾选 **"Add Python to PATH"**。

### 2. 检查环境

双击 `测试环境.bat`，确认 Python、PyTorch、OpenCV、PyQt5 等依赖均已安装。

### 3. 安装依赖

```bash
pip install ultralytics PyQt5 opencv-python numpy Pillow matplotlib seaborn scikit-learn pandas tqdm pyttsx3
```

如需 GPU 加速：
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

### 4. 启动系统

| 方式 | 操作 |
|------|------|
| GUI 模式 | 双击 `启动检测系统.bat` 或执行 `python app.py` |
| 命令行模式 | 双击 `命令行检测.bat` 或执行 `python inference.py` |
| 快速测试 | 双击 `快速测试.bat` 用 test_images 目录进行测试 |

## 检测模式

系统提供三种检测模式，通过**工具栏下拉框**或**右侧面板下拉框**均可切换，两者保持同步。

### 图片检测

- **单张检测**：点击 "打开图片" 或菜单 **文件 → 打开图片**（`Ctrl+O`）加载图片，点击 "开始检测"
- **批量检测**：点击 "文件夹" 或菜单 **文件 → 打开文件夹**（`Ctrl+Shift+O`）选择目录，系统扫描目录下所有支持的图片并逐一检测
- **拖放支持**：直接将图片文件拖拽到左侧预览区即可加载

检测结果在右侧面板的表格中实时显示：序号、缺陷类别、置信度、状态。

### 摄像头检测

- 切换至 **"摄像头检测"** 模式
- 从摄像头下拉框中选择设备（启动时自动扫描可用设备并显示分辨率）
- 点击 **"启动摄像头"** 开始实时检测
- 支持 **拍照统计**（`Space` 键或点击 "拍照统计" 按钮），每次拍照记录到右侧面板的拍照记录表中，包含时间、判定结果和缺陷类型
- 拍照记录同时汇总到统计卡片的合格/不合格计数中
- 实时显示 FPS

### 视频检测

- 切换至 **"视频检测"** 模式
- 点击 **"选择视频"** 选择视频文件（支持 mp4、avi、mov、mkv、wmv、flv）
- 自动逐帧检测并显示实时 FPS
- 检测完毕后可导出汇总报告

## 右侧面板说明

| 区域 | 说明 |
|------|------|
| 检测模式 | 下拉切换 图片 / 摄像头 / 视频，与工具栏联动 |
| 操作按钮 | 根据模式显示对应按钮（打开图片/启动摄像头/选择视频等） |

| 拍照记录 | **摄像头模式独占**，记录每次拍照的时间、判定和缺陷列表 |
| 底部操作 | 导出报告、导入模型、检测计数标签 |

## 命令行用法

```bash
# 单张图片检测
python inference.py --image test_images/crazing_271.jpg

# 批量目录检测
python inference.py --dir test_images

# 指定模型文件
python inference.py --model best.pt --image test.jpg

# 调节置信度阈值
python inference.py --conf 0.5 --dir test_images

# 显示结果并指定保存目录
python inference.py --image test.jpg --show --save-dir results/

# 调整输入尺寸和 batch size
python inference.py --dir test_images --imgsz 800 --batch-size 16
```

### 命令行参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--model` | 自动查找 | 模型权重路径 |
| `--image` | — | 单张图片路径 |
| `--dir` | — | 批量检测目录 |
| `--conf` | 0.25 | 置信度阈值 |
| `--iou` | 0.45 | NMS IoU 阈值 |
| `--imgsz` | 800 | 输入图片尺寸 |
| `--device` | 自动 | 推理设备（cpu / 0） |
| `--batch-size` | 8 | 批量推理大小 |
| `--show` | False | 弹窗显示结果 |
| `--save-dir` | runs/detect | 结果保存目录 |

## 支持缺陷类别

本系统基于 NEU-DET 数据集训练，支持以下六类钢材表面缺陷：

| 类别 | 英文名称 | 框颜色 |
|------|----------|--------|
| 龟裂 | crazing | 红色 |
| 夹杂 | inclusion | 橙色 |
| 斑块 | patches | 黄绿色 |
| 麻点 | pitted_surface | 紫红色 |
| 氧化皮 | rolled-in_scale | 深橙色 |
| 划痕 | scratches | 天蓝色 |

## 常见问题

### Q: 启动报错 "No module named xxx"

运行 `启动检测系统.bat` 自动安装依赖，或手动执行 `pip install -r requirements_cpu.txt`。

### Q: 模型文件找不到

确保 `best.pt` 和 `.py` 文件在同一目录下。系统启动时会自动在项目根目录和 `runs/train/` 子目录中搜索模型文件。

### Q: 推理速度很慢

CPU 推理属于正常表现（约 100ms/张）。如需加速，可安装 CUDA 版 PyTorch 并使用 NVIDIA GPU。

### Q: 中文显示乱码

确保系统安装了中文字体（微软雅黑或黑体）。系统会自动查找系统字体目录。

### Q: 摄像头打不开

检查摄像头是否被其他应用占用。系统启动时会自动扫描可用设备（支持 DSHOW 和系统默认后端），并在下拉框中列出。

### Q: 文件夹检测数量不对

Windows 下文件系统大小写不敏感，系统已使用 set 自动去重，确保同一文件不会被重复计入。
